HABTEWOLDE BIZUAYHU — VIDEO EDITOR PORTFOLIO

OPEN THE WEBSITE
1. Extract the ZIP file (if you downloaded the ZIP).
2. Open index.html in Chrome, Edge, Firefox or another modern browser.

PERSONALISE THE WEBSITE
1. Your portrait is already included in assets/habtewolde-bizuayhu.jpg. To replace it, click “Change photo +” while viewing the page (temporary preview), or replace that image file with your preferred portrait using the same filename.
2. Open index.html in a text editor such as VS Code or Notepad.
3. Near the bottom, find SITE_CONFIG and add your real email, Instagram, YouTube and Behance links.
4. Find the PROJECTS list and replace the sample descriptions and empty videoUrl values with your own project information and video links.
   - YouTube/Vimeo: use an EMBED link, not the normal watch/share URL.
   - MP4: use a relative path such as "videos/my-project.mp4" and put the video file in a videos folder.
5. Save index.html and refresh the browser.

NOTES
- The project tiles are editable starter placeholders, not claims that those projects have been completed.
- The contact/social links need your real details before publishing.
- This is a static website. To put it online, upload the folder to a web host such as GitHub Pages, Netlify or your own hosting account.
